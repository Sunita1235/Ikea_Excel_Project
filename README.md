# 🛒 IKEA Sales Analysis Dashboard | Microsoft Excel

An interactive Excel dashboard analyzing 30,000+ sales records to understand revenue, orders, products, customers and regional performance.

---

## 📌 Project Overview
- Analyzed **30,000+ sales records** across revenue, orders, products, customers, regions, delivery status and customer segments
- Cleaned, transformed and validated the data using Excel formulas
- Built an interactive dashboard with **KPI cards, Pivot Tables, Pivot Charts, Slicers and dynamic filters**
- Used lookup and conditional formulas to answer business questions

## 🛠️ Tools & Concepts
Microsoft Excel · Pivot Tables · Pivot Charts · Slicers · XLOOKUP · INDEX-MATCH · SUMIFS · COUNTIFS · IF/IFS · Date Functions · Data Cleaning · Data Validation

## ❓ Business Questions Solved
- How much revenue and how many orders were generated overall?
- Which products and regions perform best?
- How are customer segments contributing to sales?
- What is the status of deliveries?

- Best Performing Zone: WEST with total revenue of ₹226.Cr
